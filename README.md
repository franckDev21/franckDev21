## About

I design, build and deploy modern web and mobile applications — **from the first pixel to the production server**.

Most developers stop at the code. I own the whole chain: a polished frontend, a robust API, Docker containers, CI/CD pipelines and a server that keeps running after I hand it over. That end-to-end ownership is what I bring to a team or a client.

- 🌍 Based in **Douala, Cameroon** — working remotely with clients in Europe and North America
- 🛠️ Currently building **Primo TCF**, a SaaS platform for TCF Canada exam preparation
- ⚙️ Deeply interested in automation, DevOps and AI-assisted development workflows
- 💬 Happy to talk about Laravel, Next.js, Docker or anything infrastructure
